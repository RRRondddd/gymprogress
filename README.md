# GymProgress · FORGE

Персональный дневник силовых тренировок: React 19, TypeScript, Vite, Dexie / IndexedDB, Recharts и PWA. Русский интерфейс, тёмная тема, без регистрации и сервера. Пользовательские результаты при первом открытии отсутствуют.

## Запуск

Требуется Node.js 22+ и npm.

```sh
cd /workspace/gymprogress # или каталог вашего клона
npm ci
npm run dev
```

Откройте адрес, указанный Vite. Для разработки в облачной задаче используйте существующий checkout: создавать дополнительный Git worktree не требуется.

```sh
npm test          # критическая бизнес-логика и IndexedDB
npm run build     # TypeScript + production build + service worker
npm run preview   # проверка production-сборки
npm run test:e2e  # браузерные сценарии на production preview
```

Браузерные тесты автоматически запускают preview на порту 4173. В этой облачной среде используется `/usr/bin/chromium`. На другой машине замените `launchOptions.executablePath` в `playwright.config.ts` на свой путь либо удалите его и установите Chromium через `npx playwright install chromium`.

## Возможности

- Главная, тренировка, прогресс и история; настройки и редактор программ доступны с главной.
- Программы с несколькими днями, дублирование и перестановка дней, упражнений, настройка подходов и диапазона повторений. Изменения текущей тренировки не затрагивают шаблон.
- 18 базовых упражнений и создание собственных; свободные веса, тренажёры, собственный вес, отметка стороны.
- Вес с десятичной запятой, повторения, RIR, разминка, отметка выполнения; активная тренировка автоматически сохраняется и восстанавливается.
- История с календарём, редактирование, удаление с подтверждением и сохранение структуры как программы.
- Графики веса, объёма и повторений с периодами; пересчёт рекордов по истории, e1RM по Эпли только для допустимой внешней нагрузки.
- Таймер с абсолютным временем окончания, паузой, быстрыми значениями и опциональными звуком/вибрацией.
- Экспорт и проверяемый импорт JSON v1 с подтверждением полной замены данных.
- Локальные шрифты, manifest, иконки и service worker. Основные функции работают офлайн после первой успешной загрузки production-версии.

## Данные и расчёты

`src/domain.ts` содержит типы, валидацию, расчёты, создание независимых копий, завершение и проверку резервных копий. `src/storage.ts` — хранилище. `src/App.tsx` и `src/style.css` — интерфейс. Все данные находятся в IndexedDB текущего origin, база `gymprogress`, версия схемы 1. Запись сериализована; завершение и импорт применяются только после успешного сохранения. При ошибке выводится сообщение с возможностью повторить запись и экспортировать данные.

Объём учитывает только выполненные рабочие подходы (вес × повторения), без автоматического удвоения для сторон и без прибавления массы тела. Разминка исключается из основных рекордов и графиков. e1RM: `вес × (1 + повторения / 30)` для 2–10 повторений; для одного повтора — фактический вес; для собственного веса — не рассчитывается.

Регулярно используйте **Настройки → Экспорт JSON**. Очистка браузера, удаление данных сайта или смена домена/браузера могут удалить или скрыть дневник. Между устройствами данные переносятся JSON-файлом. Одновременное редактирование в нескольких вкладках не поддерживается: открывайте одну вкладку дневника.

## GitHub Pages и телефон

Подготовлен `.github/workflows/deploy.yml`: при push в `main` он устанавливает зависимости, запускает unit-тесты, собирает и публикует `dist` через GitHub Pages. Публикация из этой рабочей среды не выполнялась.

1. Сохраните код в GitHub (commit и push / merge в `main`).
2. В репозитории откройте **Settings → Pages → Source → GitHub Actions**.
3. Проверьте успешное выполнение workflow **Deploy GymProgress** во вкладке Actions.
4. После успешной публикации откройте на телефоне `https://RRRondddd.github.io/gymprogress/`.
5. Android / Chrome: меню → «Установить приложение» или «Добавить на главный экран». iPhone / Safari: «Поделиться» → «На экран Домой».
6. Дождитесь первой полной загрузки с интернетом. Затем откройте приложение и проверьте его в авиарежиме.

Приложение использует навигацию внутри одного HTML-документа без серверных маршрутов, поэтому не требует SPA-редиректов Pages. Базовый путь `/gymprogress/` задан в `vite.config.ts` и ссылках на иконки `index.html`; при смене имени репозитория/домена обновите эти пути.

При обновлении появляется предложение обновить приложение; service worker не удаляет IndexedDB. Перед обновлением или сменой браузера полезно экспортировать JSON.

## Проверки и ограничения

Автоматические unit-тесты покрывают объём, исключение разминки, Эпли, числовые поля, независимость шаблона, рекорды и удаление данных, резервные копии и восстановление IndexedDB. Playwright проверяет запись и восстановление, завершение, правку истории и пересчёт, программы, экспорт/импорт, офлайн-перезагрузку и ширины 320, 390 и 1440 px.

Физические устройства Android/iOS не тестировались. Вибрация/звук и установка зависят от браузера. Фоновые уведомления при блокировке не гарантируются, но таймер восстанавливается по абсолютному времени. PWA-кэш проверяется в production, в dev service worker отключён. Персональные данные не отправляются на сервер. Синхронизации и автоматических облачных резервных копий нет.
